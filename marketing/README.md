## Como exportar o PDF

1. Abra `presentation.html` no navegador.
2. Pressione **Ctrl+P**.
3. Defina: destino **Salvar como PDF**, margens **Nenhuma**, ative **Gráficos em segundo plano**.
4. Salve como `EDY_Shield_v2.0.pdf`.
