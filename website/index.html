Features

Ferramentas defensivas, modulares e tipadas

Cada módulo é um plugin cidadão executado via PluginManager — a mesma via para todos.

Hash Checker

SHA-256, SHA-1 e MD5 de texto, bytes ou arquivo — com whitelist de algoritmos e comparação em tempo constante.

Log Analyzer

Detecta falhas de login, erros, avisos e eventos críticos em arquivos .log/.txt com estatísticas por severidade.

File Integrity Monitor

Baseline criptográfica + detecção de arquivos novos, modificados e removidos — digest como fonte de verdade.

Checksum Files

Criação e verificação de SHA256SUMS, SHA1SUMS e MD5SUMS — com exit codes 0/1/2 para automação.

Batch Hashing

Hashes de múltiplos arquivos e diretórios com varredura recursiva, ordenação determinística e tratamento individual de erros.

Console SOC

UI web dark com Dashboard, Histórico e Relatórios (JSON/TXT/HTML) — servida por HTTP 100% stdlib.

FAQ

Perguntas frequentes

O EDY Shield é 100% biblioteca padrão mesmo?

Sim. O core (app/core) usa apenas a stdlib do Python 3.12 (hashlib, hmac, pathlib, dataclasses, argparse, http.server). Nenhuma dependência de terceiros no runtime (ADR-001). As dev dependencies (pytest, mypy, ruff) ficam pinadas e são apenas para desenvolvimento.

Posso usar em produção?

O projeto está em desenvolvimento ativo (v2.0.0-dev). Para verificações de integridade em sistemas próprios ou autorizados, sim. Consulte SECURITY.md e THREAT_MODEL.md antes de dependências críticas.

O que é o File Integrity Monitor?

É o módulo v2.0: cria uma baseline criptográfica de um diretório (hashes + metadados) e, em varreduras posteriores, detecta arquivos novos, modificados e removidos — com relatórios em JSON, TXT, HTML e Markdown.

Como reportar uma vulnerabilidade?

Divulgação responsável: reporte de forma privada conforme SECURITY.md — sem disclosure público antes do fix. O projeto mantém um modelo de ameaças em THREAT_MODEL.md.

Onde posso contribuir?

Veja CONTRIBUTING.md. Todo código novo precisa de testes com cobertura ≥ 90%, mypy strict 0 issues, ruff limpo e sem dependências de terceiros no core.

Pronto para defender seus dados?

Explore o repositório, leia a documentação e contribua com o projeto.
