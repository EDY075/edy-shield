# ADR-004: CLI via argparse (stdlib) — Typer reservado para v2+

- **Status:** Aceito / Implementado via ADR-007
- **Data:** 2026-08-01
- **Decisores:** jr (Tech Lead), ATLAS (Arquiteto)
- **Referenciado em:** `ARCHITECTURE.md` §9, ADR-007

## Contexto

O projeto precisava de uma CLI para `edyshield hash` e `edyshield verify`. Alternativas:
- **`argparse`** (stdlib) — madura, comprovada
- **Typer** (based on Click) — UI rica, autocomplete, help bonito
- **Click** (popular em Python) — inclinado, mas overkill demais

## Decisão

Usar `argparse` na v1 (implementado em `app/cli/hash_cmd.py`). Typer só entrará em v2+,
caso a UX de CLI justifique.

Motivos:
- Zero deps (ADR-001)
- Suficiente para 2 subcomandos (`hash`, `verify`)
- Módulo existente facilita migração futura para Typer (backend e APII separados)

## Consequências

### Positivas
- ✅ Runtime deps mantido a zero
- ✅ Compatível com todos Python 3.12

### Negativas
- ⚠️ UX mais simples (autocomplete limitado, help básico)

## Pendências
